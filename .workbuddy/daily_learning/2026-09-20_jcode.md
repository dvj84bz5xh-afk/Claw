### 核心发现
1. **极致 RAM 效率 harness** — Rust 实现, 1会话仅 27.8MB / 10会话 117MB, 比 Claude Code 省 ~14× RAM, 每增一会话仅 +~10MB; 首帧 14ms (Claude Code 慢 245×)
2. **语义记忆图 (Agent memory)** — 每 turn 嵌入为语义向量, cosine similarity 查记忆图; memory sideagent 被动提取存储 (semantic drift / K-turn / session-end 触发), 自动 consolidate (重组/查 staleness/查 conflict), 无需主动调记忆工具也不烧 token
3. **Swarm 多 Agent 协作** — 同 repo 多 agent 由 server 自动管理; agent A 编辑了 agent B 已读文件时, server 通知 B (code shifting under feet 检测), B 可查 diff 判断是否冲突; agent 可自主 spawn swarm (main→coordinator, spawned→workers), 支持 DM/广播/repo 级消息
4. **root/worker effort 分离** — swarm 模式下 root 推理与 worker 精力分层配置 (swarm_root_effort / swarm_deep_root_effort)
5. **mermaid-rs-renderer** — 自研 mermaid 渲染库, 1800× faster, 无浏览器/TS 依赖
6. **多 provider 统一接入** — OAuth 登录流 + 统一 OpenAI-compatible provider + OpenAI Responses WebSocket v2 (预预热 + HTTPS 回退)
