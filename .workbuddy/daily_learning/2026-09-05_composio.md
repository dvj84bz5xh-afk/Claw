### 项目概述
Composio 是工具集成平台 SDK monorepo（TS + Python 双 SDK + CLI），核心是**会话（Session）抽象**：每个会话按用户隔离，默认只暴露少量"元工具"（meta tools）在运行时动态发现、认证、执行应用工具——避免把数百个工具 Schema 塞进上下文。每会话可暴露 hosted MCP 端点；通过 Provider Adapter 适配 15+ 框架（OpenAI/Anthropic/Claude SDK/LangChain/CrewAI/AutoGen 等）。

### 核心发现
1. **Meta-tools 按需工具发现** — 会话默认只注入 discover/authenticate/execute 三个元工具，Agent 运行时按需检索工具定义，不预载全量 Schema（上下文从"数百工具"降到"3个元工具"）
2. **工具语义搜索** — `composio search` / 运行时 tool search，按意图匹配 1000+ 工具而非人工枚举
3. **Per-user Session 作用域** — 会话绑定用户，工具集/auth配置/已连接账号按会话隔离，session_id 跨轮复用（`composio.use()`）
4. **认证托管** — OAuth/API Key 集中管理，Agent 永不接触原始凭证；工具调用自动注入认证
5. **Provider Adapter 层** — 单一工具源适配 15+ 框架原生格式，新增框架只需一个 adapter
6. **每会话 hosted MCP 端点** — `mcp: true` 即把会话变成 MCP 服务器，Claude/Cursor 等 MCP 客户端直连

### 改进建议
1. **P0 tool_registry**: Meta-tools 按需工具发现 — 提供工具发现/执行元工具，替代全量工具Schema预注入，大幅节省上下文
2. **P0 tool_registry**: 工具语义搜索 — 按任务意图在注册表中检索相关工具子集（与OmO的Category-Based Delegation互补：类别枚举→语义搜索）
3. **P1 tool_registry**: Per-session 工具作用域 — 会话级限定可用工具与凭证，防止越权与上下文污染
4. **P1 tool_registry**: 统一认证托管 — 凭证集中管理+调用时自动注入，Agent 侧零密钥
5. **P2 tool_registry**: Provider Adapter 层 — 工具定义单源适配 OpenAI/Claude/MCP 等多格式
