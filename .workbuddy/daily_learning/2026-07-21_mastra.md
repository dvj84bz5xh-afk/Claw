### 学习项目: mastra-ai/mastra
- URL: https://github.com/mastra-ai/mastra
- Stars: 26,388
- Language: TypeScript
- Description: Modern TypeScript framework for AI-powered applications and agents

### 核心发现
1. **统一模型路由层** — 40+ Provider/3000+模型通过单一标准接口接入，消除多模型配置碎片化。Claw当前仅支持少数模型，需统一model_scheduler接口。

2. **图结构工作流引擎** — `.then()`/`.branch()`/`.parallel()`直觉式控制流语法 + suspend/resume持久化状态。对比Claw当前的线性workflow_graph.py，Mastra支持循环/条件/并行/子图，且能无限期暂停后恢复。

3. **20+存储后端统一抽象** — Astra/Chroma/ClickHouse/Couchbase/DuckDB/DynamoDB/ES/Lance/libSQL/MongoDB等统一接口。Claw当前仅JSON文件+SQLite，存储层亟需抽象。

4. **14种可观测性集成** — Arize/Arthur/Braintrust/Datadog/Langfuse/Langsmith/OTel/PostHog/Sentry等开箱即用。Claw eval_observability_skill仅6项基础能力，差距明显。

5. **LLM-as-Judge评估体系** — Judge Agent不仅评分文本，还可调用只读工具独立验证Agent声明（如检查文件是否真实创建）。Claw当前缺乏自动化评估闭环。

6. **Observational Memory+Working Memory模板** — 类人类观察记忆维持长期一致性 + Markdown模板结构化会话状态（姓名/位置/兴趣/目标/事件）。Claw的MEMORY.md可借鉴模板化设计。

7. **MCP Server原生创作** — 不仅消费MCP，还能将Agent/Tool/Workflow暴露为MCP Server。Claw目前仅消费端，缺少服务端能力。

8. **Input/Output Processor管道** — TokenLimiter/Redaction/Moderation等处理器在LLM前后链式执行。Claw context_injector可扩展为Processor管道架构。

### 改进建议
1. **存储抽象层(P0)** — 创建`StorageAdapter`统一接口，先支持SQLite/JSON/Memory三种后端，后续按需扩展。替换当前硬编码文件读写。

2. **可观测性矩阵(P0)** — 参考Mastra的`observability/`目录设计，为Claw增加OTel exporter + Langfuse/Langsmith连接器，从6项扩展到10+集成。

3. **LLM-as-Judge评估闭环(P0)** — 进化引擎每次学习后自动触发Judge Agent评估：检测建议是否重复、与已有实现冲突、是否有实际价值。替代当前纯人工审核。

4. **工作流持久化恢复(P0)** — 为夜间进化引擎添加检查点机制：每阶段(collect/enrich/select/dispatch)完成后序列化状态到存储，中断后从断点恢复。

5. **MCP Server创作(P1)** — 将Claw Agent/Skill/Tool暴露为MCP Server，让其他IDE(Cursor/Windsurf)也能调用Claw能力。
