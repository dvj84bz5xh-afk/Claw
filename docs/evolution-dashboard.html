核心创新:
1. '录下的运行就是测试'(The recorded run IS the test): 手写数据集是对'可能出什么错'的猜测, 生产已给出真正失败那次的完整轨迹(输入/工具调用/模型响应) — 一切评分聚类建议与CI结论都从trace派生
2. fail-to-pass契约(抗作弊): 冻结用例必须'旧代码失败+修复后通过'两条记录都留档, 否则晋升不被信任 — 没有红过的用例不算修复证据
3. 失败聚类: 结构签名+语义嵌入, 31次坏运行压成1个issue带计数, 并建议'哪个evaluator本可抓到它'
4. judge校准闸门: 人工标注对照统计漏报率与过报率, 达标前只给advisory不参与拦截; 配套advisory verdict先观察后拦截
5. 零成本确定性重放: 重放靠录制fixtures不调模型不调工具, CI跑数百agent用例$0且确定性 — 这是agent回归测试能落地的前提
6. 多轮行为用scenario: 脚本化对话 或 红队模型自主追求的对抗目标(goal achieved = FAIL), 把被引导走偏变成可判定失败
7. 摄入blob-first: 原始先落S3再入队, 队列丢消息不丢证据; evaluator是trace表上的列而非独立tab, SSE流式写回
8. CI闸门: gate非零退出+commit status+PR评论; 告警为'何时+做什么'流程图(闸门失败/出现新失败模式/速率越线)
