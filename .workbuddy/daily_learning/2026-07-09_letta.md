### 项目定位

> *"Build AI with advanced memory that can learn and self-improve over time."*

原名MemGPT，核心是**有状态Agent平台**——将持久化记忆作为Agent的一等公民，通过Skills+Subagents实现持续学习与自我改进。

### 核心技术发现

1. **记忆驱动架构（Stateful Agent）**
   - PostgreSQL + pgvector 向量数据库持久化记忆
   - 复合索引 `(organization_id, agent_id, last_message_at)` 优化检索
   - `last_message_at` 时间戳按活跃度排序对话
   - 全局上下文窗口可控（默认128k，可配置clamp）

2. **自我改进循环（Self-Improvement）**
   - 预构建的记忆Skill：Agent随时间学习并自我改进
   - 技能系统（Skills） + 子Agent（Subagents）扩展能力
   - 自我开发（Dogfooding）：使用Letta Code开发自身

3. **多后端统一SDK**
   - 三层部署：Constellation（云端）/ Local（本地）/ App Server（自托管）
   - TypeScript SDK一次编写，`backend`参数切换部署模式
   - 本地模式无需API Key，零配置启动

4. **生产级可观测性**
   - OpenTelemetry（OTEL）全链路指标采集
   - 事件循环看门狗（event loop watchdog）：线程级检测>15s阻塞，每5s心跳
   - Webhook支持步骤完成通知
   - OTEL指标导出至Datadog

5. **安全沙箱体系**
   - 代码执行沙箱隔离（sandbox/目录）
   - JSON替代pickle安全传输工具结果（修复反序列化漏洞）
   - 会话恢复机制：`resumeSession()` 实现有状态流式传输

### 改进建议

1. **记忆系统PG化**（P0）：当前Claw使用JSON文件树做记忆，迁移到PG+pgvector可实现语义检索+多维度复合索引+并发安全
2. **事件循环看门狗**（P0）：Agent长时间运行时可能阻塞，引入线程级watchdog（15s阈值+5s心跳）可提前发现性能瓶颈
3. **多后端部署抽象**（P1）：当前Claw仅本地运行，借鉴Letta的SDK设计可实现本地/云/自托管灵活切换
4. **自我开发闭环**（P1）：Letta用自身Agent开发自身——Claw可建立"学习→改进→自测"的dogfooding循环
