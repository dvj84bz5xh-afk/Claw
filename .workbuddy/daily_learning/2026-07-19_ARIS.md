### 核心发现
1. **睡眠自主研究闭环** — ARIS让Claude Code在用户睡觉时自动完成ML研究：论文评分→弱点识别→实验运行→叙事重写，完全自主。这与Claw夜间进化引擎理念完全一致，但ARIS已实现生产级闭环（v0.4.22，18个迭代版本）。
2. **纯Markdown Skill架构** — 零框架、零锁定、零基础设施。每个Skill是单个`SKILL.md`文件，任何LLM Agent都能读取。已捆绑79个Skill，覆盖论文写作、实验队列、引用审计、海报生成等全流程。支持Claude Code/Codex/Cursor/Trae/Antigravity/Copilot CLI/OpenClaw等8+工具。
3. **对抗性交叉模型审查** — 不用自博弈（单一模型审查自身易陷入局部最优），而是Claude Code执行 + Codex MCP（或Kimi/DeepSeek/GLM）作为独立审查者。审查控制面采用"两梯队原则"（ultra深度审计 + xhigh底线），实现真正的外部质量控制。
4. **元优化自我进化** — `/meta-optimize`命令分析执行日志→自动提出SKILL.md补丁。这是真正的技能自进化，非简单的知识积累。v0.3.5起已内置，支持从日志中提取模式、识别低效环节、生成改进建议。
5. **反自主研究审计（Anti-Autoresearch）** — 自研46种完整性hack模式（8大家族A-H）+ 13种零权重AI风格印象 + 2种咨询信号 = 61种信号端到端检测。用于检测自我一致性缺陷和捏造，确保自主研究的可信度。
6. **MCP原生工具调度** — v0.4.17实现完整MCP协议栈：stdio握手、版本协商（2025-03-26/2025-06-18/2025-11-25/2024-11-05）、NDJSON传输、按工具调用、软降级、审批门。支持零API key审查（ChatGPT订阅通过Codex MCP接入）。
7. **研究Wiki持久知识库** — 论文/想法/实验/声明的持久化存储 + 关系图谱。不是简单文件dump，而是带关联的知识网络，支持跨会话记忆延续。

### 改进建议
1. **【P0】实现Claw `/meta-optimize` 自进化命令** — 参考ARIS的`meta-optimize`机制，在每日09:00进化任务完成后，自动分析当日学习日志（learning_tracking.json + evolution_log.jsonl），识别高频低效模式，生成SKILL.md补丁建议。当前Claw进化引擎是"只学不改"，ARIS证明"学了还要自我优化"才能形成闭环。
2. **【P0】制定Claw Markdown Skill标准** — 参考ARIS的`SKILL.md`格式（触发器+行为+示例+前置条件），将SkillsHub现有技能全部标准化为纯Markdown格式，确保任何Agent（Claude Code/Hermes/其他）都能读取执行，消除框架锁定。当前技能格式不统一，部分依赖Claude Code特定语法。
3. **【P0】引入交叉模型审查机制** — 在Claw多Agent协作群（WorkBuddy+Claude Code+Hermes）中，引入强制交叉审查：关键代码/分析报告生成后，必须经另一模型Agent审查通过。参考ARIS的"两梯队原则"（ultra深度审计+xhigh底线），为Claw设置质量门禁。当前Claw缺乏系统化的多Agent质量审查。
4. **【P0】建立反进化完整性审计** — 参考ARIS的Anti-Autoresearch（46种hack模式），为Claw进化引擎建立"改进建议质量审计"机制：检测重复建议、过度泛化、无根无据的改进、与已有实施冲突的建议。当前218个改进项中可能存在低质量或重复项，需要自动清洗。
5. **【P1】升级MCP连接器稳定性** — 参考ARIS的MCP实现（版本协商、NDJSON、按服务器超时、软降级、审批门），修复Claw MCP连接器的已知问题（协议版本不匹配、超时处理不当、错误信息泄漏凭证）。ARIS v0.4.17-0.4.22的MCP演进路径提供了完整的最佳实践参考。
6. **【P1】构建项目级研究Wiki** — 将Claw的`.workbuddy/memory/`从简单文件集合升级为带关系图谱的知识库（论文/项目/技能/改进项的关联网络），支持跨会话查询"与X相关的所有改进项"。当前MEMORY.md是线性文档，缺乏关联结构。
