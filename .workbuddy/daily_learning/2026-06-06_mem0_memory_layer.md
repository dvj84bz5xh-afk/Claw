### 核心发现
1. **单轮记忆提取算法**: 仅需1次LLM调用完成记忆提取，无复杂Agent循环。LoCoMo基准得分91.6(+20pt)，LongMemEval得分94.8(+27pt)，检索延迟仅0.88s
2. **混合检索引擎**: 并行融合语义向量检索、BM25关键词检索、实体匹配检索三类结果，大幅提升检索准确率
3. **多级记忆架构**: 同时支持用户级(user)、会话级(session)、智能体级(agent)三层记忆，与Claw现有三层架构高度吻合
4. **实体感知记忆**: 自动提取记忆中的实体并建立跨记忆关联链，提升上下文关联性

### 可借鉴点
| 优点 | 优先级 | 说明 |
|------|--------|------|
| 单轮提取算法(1次LLM调用) | P0 | Claw当前依赖手动指令写入记忆，可引入自动提取降低认知负担 |
| 混合检索(语义+关键词+实体) | P1 | Claw检索纯文本匹配，混合检索可提升历史记忆命中率 |
| 实体关联网络 | P1 | 建立跨对话实体关系图，提升长期上下文连贯性 |
| Dashboard可视化 | P2 | 管理端UI可监控记忆量/检索延迟/Agent行为 |

### 改进建议
1. **P0-自动记忆提取**: 借鉴mem0单轮提取算法，在每次对话结束后自动提取关键信息写入memory层，无需手动指令触发。参考其LoCoMo benchmark验证提取质量
2. **P1-混合检索升级**: 为Claw三层记忆添加向量化存储(Qdrant本地部署) + BM25索引，实现语义+关键词混合检索，替换当前纯文件glob查找
3. **P2-记忆仪表盘**: 创建memory健康度仪表盘，监控各层记忆量、检索命中率、过期清理等指标

### 技术亮点
- **部署模式**: SDK库 / 自托管服务器 / 托管云平台(三种模式自由切换)
- **生态集成**: 原生支持Langgraph/CrewAI，提供Skills插件给Claude Code/Cursor
- **API设计**: `memory.add()` + `memory.search()` 两个核心接口，按user_id过滤
- **时间感知**: 自动区分"过去事件/当前状态/未来计划"三类时间维度
