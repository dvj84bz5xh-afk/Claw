### 项目概述
Cognee是开源AI记忆平台，为AI Agent提供跨会话持久化长期记忆。核心能力：自托管知识图谱 + 向量检索混合架构，支持多格式文档摄入、自动构建实体关系图。

### 核心发现

1. **四操作记忆API (remember/recall/forget/improve)**
   - `remember`: 存储到知识图谱(执行 add + cognify + improve 流水线)
   - `recall`: 智能路由搜索(自动选择最佳搜索策略)
   - `forget`: 按数据集/关键词删除
   - `improve`: 自我优化记忆质量
   - Claw现状：仅文件级读写，无结构化记忆操作API

2. **双层级记忆架构 (Session + Permanent Graph)**
   - Session层：快速缓存，同步写入
   - Permanent层：后台同步到知识图谱
   - `remember(text, session_id="chat_1")` → 先写session，后台sync到graph
   - `recall(query, session_id="chat_1")` → 优先查session，穿透到graph
   - Claw现状：MEMORY.md + 日志文件，无分层路由

3. **知识图谱 + 向量检索混合引擎**
   - 支持Kuzu(Ladybug)/Neo4j/pgvector三种图数据库
   - 自动分块(chunking) → 向量嵌入 → 图谱三元组提取
   - 认知科学驱动的本体生成(cognitive-science-grounded ontology)
   - Redis分布式锁解决并发冲突
   - Claw现状：纯文件glob查找，无图数据库

4. **生命周期钩子集成 (5个Hook)**
   - SessionStart → 初始化记忆
   - PostToolUse → 捕获工具调用
   - UserPromptSubmit → 注入相关上下文
   - PreCompact → 上下文压缩前保存关键记忆
   - SessionEnd → 将session数据桥接到永久图谱
   - Claw现状：无生命周期钩子

5. **代码图谱管道 (Code Graph Pipeline)**
   - 解析代码仓库为调用图(call graph)
   - 自动提取函数调用关系、依赖链
   - 对Claw理解自身代码结构有直接价值

### 改进建议

1. **P0: 为Claw记忆系统实现四操作API**
   - 在`memory_system.py`中增加`remember/recall/forget/improve`标准接口
   - `remember`: 自动提取关键信息写入MEMORY.md + 日志
   - `recall`: 语义检索记忆（先用关键词+glob，后续可升级向量）
   - `forget`: 标记过期/清除记忆条目
   - `improve`: 定期压缩/合并/去重记忆内容

2. **P0: 实现Session+Permanent双层级记忆**
   - Session层：当前会话快速缓存（内存dict）
   - Permanent层：磁盘MEMORY.md + 日志文件
   - 会话结束后自动从Session sync到Permanent
   - 查询时优先Session，miss时穿透Permanent

3. **P1: 添加5个生命周期钩子**
   - 参考Cognee的SessionStart/PostToolUse/UserPromptSubmit/PreCompact/SessionEnd
   - 在Claw的agent_orchestrator中注册钩子
   - PostToolUse自动记录关键操作到记忆
   - PreCompact在上下文压缩前保存关键上下文

4. **P1: 代码图谱管道**
   - 解析Claw agent-core目录结构
   - 自动生成模块依赖图和函数调用图
   - 增强代码理解的上下文注入

5. **P2: 认知本体自动生成**
   - 从对话中自动提取实体和关系
   - 构建项目知识图谱
   - 支持图谱查询辅助决策
