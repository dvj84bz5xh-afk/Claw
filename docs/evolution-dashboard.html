4. 三级作用域物理分离: ~/.trail(个人, 永不提交) / repo/.trail(关于代码, 随代码提交) / team workspace(跨仓); agent自行判断归属
5. always-follow硬标记: 标了的条目即使被要求也不违背, 停下并指出条目与添加者 — 与failproofai元策略不可暂停同构, 对象从策略换成知识
