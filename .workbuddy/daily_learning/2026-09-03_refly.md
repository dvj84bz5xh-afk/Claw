### 核心发现
1. **"Skills are infrastructure, not prompts"** — 核心主张：Skill 不是一段提示词，而是确定性的、可版本化、可复用的能力资产。企业 SOP → 3分钟编译为可执行 Skill。
2. **Vibe DSL 编译范式** — 用自然语言描述业务逻辑（Vibe Mode），Model-Native DSL 把意图编译为高性能确定性 Skill，显著降低 token 成本。
3. **Intervenable Runtime（可介入运行时）** — 执行中途可暂停/审计/改向（Steer logic mid-run）；失败时 Hot-fix 热修当前运行而非从头重启；确定性保证+失败恢复，打破 AI 执行"黑盒"。
4. **Universal Export（单源多形态分发）** — 一份 Skill 可导出为 Claude Code/Cursor 原生工具、MCP Server、REST API、Slack/飞书/Teams Webhook，兼容 AutoGen/LangChain/Manus 等框架。
5. **Central Skill Registry 资产治理** — 中心化注册表+版本控制+审计日志+团队协作，把脚本升级为受治理的组织资产（对比 n8n 模板复制漂移 vs LangChain 无注册表）。
6. **Refly CLI 一键装/发** — `refly skill install/publish`、`npx skills add`，社区技能仓库 registry 化分发。

### 改进建议
1. **skill_system (P0)**: 为 Claw SkillHub 增加 Vibe 编译器 — 用户自然语言描述工作流/录制流程，自动生成标准 SKILL.md（含触发条件+步骤+校验规则），对标 refly 的 3 分钟 SOP→Skill。
2. **agent_orchestrator (P0)**: 引入 Intervenable Runtime 语义 — 工作流节点执行可暂停审计、运行中改向；失败时支持 hot-fix 补丁后继续而非整链重启（与 Mastra 检查点断点续传互补）。
3. **skill_system (P1)**: SkillsHub 升级为资产注册表 — 每个 Skill 记录版本历史/变更审计/依赖，支持团队共享与回滚。
4. **skill_system (P1)**: SKILL.md 单源多形态导出 — 一套定义自动生成 MCP Server 描述/CLI 命令/REST API 端点，降低多端维护成本。
5. **tool_registry (P2)**: Skill 元数据增加确定性 Schema（input/output/校验/恢复策略），使 Skill 从 prompt 文本升级为可验证的 capability。
