### 学习项目: deepset-ai/haystack
- URL: https://github.com/deepset-ai/haystack
- Stars: 26,425 | Forks: 3,086
- 语言: Python | 许可: Apache-2.0

- 定位: 生产级 LLM 应用编排框架（Haystack 3.0），以**上下文工程**为核心设计哲学 — 对信息在到达模型前的检索、排序、过滤、组合、结构化、路由提供显式控制

### 核心发现
1. **Agent 生命周期钩子 + 开箱可观测** — `before_llm`/`before_tool`/`on_exit` 钩子实现护栏与自定义逻辑；`step_count`/`token_usage`/tool calls 原生追踪，监控与成本控制开箱即用
2. **SkillToolset 渐进式技能发现** — 技能描述只在需要时才进入上下文（与 composio Meta-tools 思路互相印证，且直接作用于 Skill 层）
3. **上下文工程显式化** — 检索/记忆/工具/生成全链路透明可追溯，pipeline 中显式定义信息流而非隐式提示词堆砌
4. **单一 Pipeline 同步/异步双模** — 一个 Pipeline 定义即可同步或异步运行、逐 token 流式输出；Agent 支持并发工具调用
5. **透明控制流** — 循环、分支、条件逻辑显式建模，精确控制上下文在 pipeline 与 agent 工作流中的流动
6. **Hayhooks 部署层** — Pipeline/Agent 一键包装为 REST API 或 MCP Server，兼容 OpenAI chat completion 端点，可接入 open-webui 等聊天 UI

### 改进建议
1. **P0** `skill_system`: 渐进式技能发现（SkillToolset模式）— Skill 描述不预载，运行时按任务意图按需注入，与 composio 工具语义搜索形成 Skill 层+工具层双补
2. **P0** `eval_observability`: Agent 内建 token_usage/step_count 追踪 — 每个 Agent 运行自动产出成本与步骤指标，无需外部埋点（与 plano 零代码信号互补：plano 在调度层，haystack 在 Agent 层）
3. **P1** `agent_orchestrator`: 生命周期钩子补全 before_llm/before_tool/on_exit 级别（现有 AgentHook 三层基础上对齐 nanobot+haystack 两家实践）
4. **P1** `context_injector`: 显式上下文路由管道 — 检索→排序→过滤→组合→结构化→路由六阶段显式建模，替代隐式拼装
5. **P2** `claw_integration`: Pipeline 部署层 — 将 Claw 工作流一键暴露为 REST API/MCP Server/OpenAI 兼容端点
