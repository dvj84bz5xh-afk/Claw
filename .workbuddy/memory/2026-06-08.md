## 22:01 P0 #21 落地 - WorkflowGraph 图结构工作流编排引擎

### 落地项目：P0 #21 (maf-091207)
**来源**: microsoft/agent-framework ⭐10,835
**改进**: 图结构工作流编排（sequential/concurrent/handoff/group）

### 实施内容
1. **新增 `agent-core/workflow_graph.py`** (~1500行) — 核心组件:
   - **6种运行模式**:
     - `Sequential`: 顺序链（节点逐个执行，数据传递）
     - `Concurrent`: 并行分支（多线程同时执行，共享输入）
     - `Group`: 分组聚合（并行+聚合器合并结果）
     - `Condition`: 条件路由（根据输入动态选择Agent）
     - `Loop`: 循环反馈（迭代直到满足停止条件）
     - `DAG`: 自由拓扑（Kahn算法自动分层+同层并行）
   - **核心数据结构**: WorkflowGraph(DAG) / WorkflowNode / WorkflowEdge / ExecutionContext
   - **WorkflowBuilder**: 流式API构建器（`.node().edge().build()`）
   - **图分析算法**: 拓扑排序(Kahn) + 环路检测(DFS三色着色)
   - **生产特性**: 线程级超时保护 / 指数退避重试 / 全链路追踪日志 / JSON序列化导出
   - **中文路由**: intent_router() + 3层匹配策略（精确/bigram/token）

2. **演示验证** (6场景全通过):
   | 场景 | 模式 | 结果 |
   |------|------|------|
   | 客服智能路由 | Condition | 4/4 正确路由 |
   | 文档处理流水线 | Sequential | 4/4, 2ms |
   | 多维度并行分析 | Concurrent | 4/4, 2ms |
   | 专家会诊分组 | Group | 3/3+聚合, 1ms |
   | DAG混合执行 | DAG | 6/6分层并行, 1ms |
   | 环路检测 | — | 正确检测a→b→c |
