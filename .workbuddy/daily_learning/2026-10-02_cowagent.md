### 项目概述
开源超级 AI 助手 + Agent Harness 参考实现（原 chatgpt-on-wechat 更名）。主动规划任务、操控电脑与外部服务、创建/运行 Skills、构建个人知识库与长期记忆、组建多 Agent 团队、通过自我进化持续成长。多 Agent、多模型、多渠道，一行安装。

### 核心发现
1. **记忆三轨互补双系统** — time-ordered 记忆（短期 context → 中期 daily → 长期 MEMORY.md）+ 按主题组织知识库（Markdown wiki），时间序与主题序两套互补，覆盖「何时发生」与「关于什么」
2. **Deep Dream 蒸馏** — 每晚把零散记忆蒸馏为精炼长期条目 + 叙事日志
3. **按主题知识库 + 可视化知识图谱** — 自动从对话策展结构化知识，维护交叉引用与索引，Web 控制台提供交互式知识图谱浏览
4. **Self-Evolution 主动跟进** — 自动审查对话改进技能、跟进未完成任务、整合记忆与知识
5. **多模态能力路由矩阵** — chat/vision/image/ASR/TTS/embedding 六能力各自路由到不同厂商（一张 provider×能力 矩阵表）
6. **MCP 单文件接入 + 按需检索** — 一个 mcp.json 搞定，支持 stdio/SSE、热重载、on-demand 工具检索、零代码
7. **Tools/Skills 分层** — 工具是原子能力（read/write/bash/browser），技能是高阶工作流（manifest 组合多工具）
8. **多 Agent 团队** — 每 Agent 独立 role/model/skills/knowledge/workspace，共享会话协作

### 改进建议
1. **rag_engine：按主题知识库 + 可视化知识图谱** — 在现有正交分区记忆之外，增加「按主题 Markdown wiki + 知识图谱可视化浏览」，交叉引用自动维护（P0，价值高：Claw 记忆强于时间序，缺主题序知识沉淀）
2. **memory_system：时间序 + 主题序双系统互补** — 明确「何时发生」走时间序记忆、「关于什么」走主题知识库，两套索引互补（P0）
3. **model_scheduler：多模态能力路由矩阵** — 声明式路由从「任务→模型」升级为「能力×厂商」矩阵，chat/vision/image/ASR/TTS/embedding 各自独立路由（P1）
4. **tool_registry：MCP 按需检索 + 热重载** — 避免工具全量注入，运行时按需检索 MCP 工具，mcp.json 改动热重载（P1）
5. **agent_orchestrator：多 Agent 团队独立上下文** — 每 Agent 独立 role/model/skills/knowledge，共享会话内协作（P2）
