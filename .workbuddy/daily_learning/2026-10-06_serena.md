### 核心发现
1. **符号级代码工具 (Symbol-level)** — 检索/编辑/重构都在符号级别(函数/类/变量)而非行号/文本搜索, agent 像老练开发者一样利用 IDE 能力。
2. **关系结构利用** — find referencing symbols(引用查找)、type hierarchy(类型层次)、find implementations(实现查找), 不必读整个文件即可理解代码结构与关系。
3. **符号化编辑 (Symbolic Editing)** — replace symbol body / insert after symbol / safe delete, 比搜索替换更可靠且省 token。
4. **精确重构工具** — rename / move / inline / propagate deletions, 避免 agent 被迫用不可靠的 search-replace。
5. **agent-first tool design** — 工具面向 AI agent 设计, 用高层抽象替代行号/正则等低层原语。
6. **MCP 集成 + LSP 抽象层** — 通过 MCP 暴露给任意 client(Claude Code/Codex/Cursor), 双后端(LSP 开源 40+语言 / JetBrains 插件)。
7. **交互式调试** — REPL 风格, 断点/变量检查/表达式求值/执行流控制。
