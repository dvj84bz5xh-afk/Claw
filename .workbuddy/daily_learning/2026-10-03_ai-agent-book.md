### 项目概述
《深入理解 AI Agent：设计原理与工程实践》（李博杰 著）开源主仓库。围绕核心公式 **Agent = LLM + 上下文 + 工具**，10 章把 AI Agent 从原理讲到工程实战，含 109 个配套实验，15 种语言，全书正文/配图/实验全部开源。

### 核心发现
1. **核心公式 Agent = LLM + 上下文 + 工具**，且「Harness 工程才是竞争力」——智能来自模型，但拉开差距的是 harness 工程
2. **上下文工程决定能力上限**（第2章）——KV Cache 管理、提示工程、Agent Skills、上下文压缩四支柱
3. **工具三分类 + 主动工具发现**（第4章）——工具分感知/执行/协作三类，agent 主动发现可用工具而非被动等注入
4. **观察与动作空间扩展**（第6章）——从模态与时序两维度扩展：异步与事件驱动、语音、Computer Use、机器人操作
5. **评估驱动选型**（第7章）——评估环境 + 指标 + 统计显著性，把表现变成可比较信号，评估结果反过来驱动模型/工具选型
6. **持续进化四层面**（第9章）——从运行轨迹获得学习信号，分层更新知识 / 指令 / 程序 / 参数
7. **多 Agent 协作**（第10章）——群体智能高于个体，上下文共享/隔离权衡，涌现「Agent 社会」

### 改进建议
1. **tool_registry：工具三分类 + 主动工具发现** — 按「感知/执行/协作」能力域组织工具，agent 主动检索发现可用工具而非被动全量注入（P0，价值高：与已有的工具语义搜索/渐进式发现互补，补齐「主动发现」维度）
2. **eval_observability：评估统计显著性 + 评估驱动选型** — 用统计显著性判断改进是否真实有效，评估结果反过来驱动模型/工具选型，而非只记指标（P0）
3. **claw_integration：异步与事件驱动交互** — 从请求-响应扩展到事件驱动/异步，观察与动作空间按模态+时序两维扩展（语音/Computer Use/机器人）（P1）
4. **context_injector：上下文工程四支柱显式化** — KV Cache 管理 + 提示工程 + Agent Skills + 上下文压缩，作为统一的上下文工程框架（P1）
5. **claw_integration：持续进化四层面** — 从运行轨迹获得学习信号，按「知识/指令/程序/参数」四层面分层更新，明确每层更新触发条件（P2）
