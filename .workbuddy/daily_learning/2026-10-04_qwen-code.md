### 核心发现
1. **Agentic out of the box** — Auto-Memory、Auto-Skills、SubAgents、Agent Teams、MCP 零配置开箱即用, 动态工作流无需显式编排。
2. **Agent Arena 多模型同任务对抗评估** — 同一任务让多个模型 head-to-head 对比, 评估结果直接驱动选型 (超越单一模型基准)。
3. **Daemon Mode (`qwen serve`)** — Agent 作为常驻守护进程, 多客户端共享同一会话状态与上下文, 避免重复建连接。
4. **Self-iterating dogfooding** — Qwen Code 用自己的 agent + 模型给自身仓库提交 issue/PR/审查/测试, 形成自举开发闭环。
5. **SWE-bench 工程化评估** — SWE-bench_Verified 500 例×3 trials×7 版本, 平均 77.8% (pass rate 84.6%), 用可复现统计评估量化每次版本迭代。

### 改进建议
1. eval_observability: 引入 Agent Arena 机制 — 同一任务并发派发给多模型, head-to-head 对比结果 + 统计显著性判断, 评估结果直接驱动模型/工具选型 (深化已有"评估驱动选型")。
2. claw_integration: 引入 Daemon Mode — `claw serve` 常驻守护进程, 多客户端共享同一会话状态与上下文, 在已有"Daemon状态保持"上升级为多客户端共享。
3. memory_system: Auto-Memory 零配置 — 会话级记忆自动捕获与持久化, 无需用户显式配置/命令。
4. skill_system: 预置 Built-in Skills 原子技能集 — /review、/batch、/loop、/bugfix 等高频命令开箱即用。
5. claw_integration: Self-iterating dogfooding — 让 Claw 自身 agent 维护 Claw 仓库(提交 issue/PR/审查/测试), 形成自举进化闭环。
