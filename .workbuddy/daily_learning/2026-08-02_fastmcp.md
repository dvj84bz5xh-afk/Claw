## 2. 核心创新点（8大支柱）

### 2.1 装饰器即协议（Decorator-as-Protocol）

```python
from fastmcp import FastMCP
mcp = FastMCP("Demo")

@mcp.tool
def add(a: int, b: int) -> int:
    """Add two numbers"""
    return a + b
```

- **类型注解 `a: int`** → 自动生成 JSON Schema
- **docstring** → 自动转为工具描述
- **返回类型** → 自动序列化
- **零样板代码**：100行协议代码压缩为3行

### 2.2 MCP Server Composition（服务器组合）

```python
# mcp.mount() - 动态挂载（live link）
main.mount("/math", math_server)
main.mount("/weather", weather_server)

# mcp.import_server() - 静态导入（copy）
main.import_server("/tools", tools_server)
```

**价值**: 把单体MCP拆分为可复用的小MCP模块，按路径命名空间组合

### 2.3 MCP Server Proxy（代理模式）

```python
proxy = FastMCP.as_proxy("https://remote-mcp.com/sse")
# 远程 SSE → 本地 Stdio 桥接
# 不可控MCP服务加逻辑层
```

### 2.4 OpenAPI/FastAPI → MCP 自动生成

```python
# 从OpenAPI规范生成MCP
mcp = FastMCP.from_openapi("https://api.example.com/openapi.json")

# 从FastAPI应用生成MCP
mcp = FastMCP.from_fastapi(app)
```

**价值**: 现有 Web API 零成本接入 MCP 生态

### 2.5 企业级 OAuth 认证（10+ Provider）

内置 Provider:
- Google / GitHub / Microsoft / Azure
- Auth0 / WorkOS / Descord
- JWT/Custom / API Keys

**独家创新**: OAuth Proxy Pattern — 让任何 Provider 都支持 Dynamic Client Registration (DCR)

### 2.6 Context 注入机制

```python
@mcp.tool
async def query_db(query: str, ctx: Context) -> str:
    await ctx.info(f"Executing: {query}")
    return await db.execute(query)
```

工具函数可直接访问 MCP 上下文（logging/progress/resources）

### 2.7 多种传输自动协商

- `stdio` — 本地CLI默认
- `streamable-http` — Web部署推荐
- `sse` — 兼容旧客户端

### 2.8 LLM-Friendly 文档规范

- `llms.txt` — sitemap 格式
- `llms-full.txt` — 完整文档
- 文档站点通过 **MCP 自身** 暴露（gofastmcp.com/mcp）

**收益**: Claw 10大模块可独立打包为可复用MCP命名空间

**目标**: `mcp = ClawMCP.from_fastapi(fastapi_app)`
**收益**: Claw 现有 FastAPI 接口零成本暴露为 MCP 工具

**目标**: `@claw.tool \n @with_auth \n @with_retry \n @with_log`
**收益**: 横切关注点与业务逻辑解耦
