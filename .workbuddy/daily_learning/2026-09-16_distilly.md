- 定位: 把一个人（离职同事/导师/前辈）的工作风格、知识、人格蒸馏成可复用的 AI Skill，实现"数字永生"。上海 AI Lab 安全中心出品，遵循 AgentSkills 开放标准。

### 核心发现
1. **专家知识蒸馏 (Expert Knowledge Distillation)** — 输入飞书/钉钉/Slack/微信消息、文档、邮件等原始材料 + 主观描述，输出一个"真的像 TA 那样工作"的 Skill。核心理念：来源材料质量 = Skill 质量。
2. **双层 Skill 架构 (Work Skill + Persona)** — 分离"工作能力"（系统、技术标准、工作流、经验）与"人格"（5层），执行时 `Persona 决定态度 → Work Skill 执行 → 以原声输出`。
3. **5 层人格模型** — hard rules → identity → expression → decisions → interpersonal，从硬规则到人际逐层刻画。
4. **增量合并 (merger.md)** — append 新文件 → 自动分析 delta → 合并进相关 section，**永不覆盖已有结论**。
5. **纠正层 (correction_handler.md)** — 对话中说"他不会那样，应该 xxx" → 写入 Correction 层，**立即生效**，无需重建整个 Skill。
6. **版本控制 + 回滚 (version_manager.py)** — 每次更新自动归档，`/colleague-rollback {slug} {version}` 回滚任意历史版本。

### 改进建议
1. **P0** `memory_system`: 增量合并机制 — 借鉴 merger.md 的 delta 分析 + 分区合并，MEMORY.md / Skill 更新时对新增材料只合并不覆盖（对齐 EverOS Markdown-as-Truth 可重建思路）
2. **P0** `memory_system`: 纠正层 — 用户纠正"应该这样"时写入 Correction 层立即生效，而非重建整份记忆，降低纠错成本
3. **P1** `skill_system`: 版本控制 + 回滚 — Skill 每次更新自动归档版本快照，支持回滚任意历史版本（当前 Claw 技能无版本历史）
4. **P1** `skill_system`: 双层 Skill 结构 — 将 Skill 拆分为 Work（能力）+ Persona（风格）两部分，执行时分离，便于复用与微调
5. **P2** `claw_integration`: 专家知识蒸馏管道 — 从历史对话/文档蒸馏专家知识为可复用 Skill（强化现有 /learn 技能为"人"级蒸馏）
