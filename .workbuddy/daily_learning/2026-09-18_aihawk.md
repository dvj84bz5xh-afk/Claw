### 核心发现
1. **反检测浏览器引擎（invisible_playwright + invisible_core）** — API 同 Playwright，但做「seed→fingerprint」确定性指纹生成，浏览器身份不被识别为自动化，规避验证码与封禁。
2. **确定性身份（`--seed`）** — 相同 seed 每次生成相同浏览器身份，避免指纹漂移被风控识别；`--profile-dir` 让登录态/Cookie 跨重启存活。
3. **代理与地理定位联动** — `--proxy` 指定代理后，timezone/locale/egress（出口IP）自动跟随，保证反检测一致性。
4. **MCP server 一键接入** — `uvx aihawk` 一条命令即可作为 MCP server 接入 Claude Code / Codex / Gemini CLI，工具标准化。
5. **配置优先级链 + 密钥安全** — 读取顺序 `--flag > 环境变量 > .env > 默认`，.env 不向上搜索；启动日志只打印变量名不打印值，避免密钥进 shell history / 进程列表。
