### 项目概述

Raven是基于EverOS构建的**自进化Agent线束（Self-Improving Agent Harness）**，核心理念是"线束即产品"——不是LLM+工具+循环的薄包装，而是围绕Agent的完整运行时环境。提供MiroThinker驱动的深度研究能力，支持多源调查。

### 核心发现

1. **Spine脊柱架构** — 单入口(submit)/单出口(emit)，每会话独立lane保证消息顺序与取消。Feature引擎通过显式handoff插入Agent循环，不互相import
2. **Sentinel主动引擎** — Agent不再被动等待用户输入；Sentinel含nudge策略+调度器，当检测到需要行动的场景主动触发
3. **Evolver自进化管道** — 基准驱动的线束自进化（benchmark-driven harness self-evolution），持续评估并优化线束参数
4. **TokenWise令牌智能** — 用量追踪+缓存放置+路由策略三合一，自动选择最优模型/缓存路径
5. **SkillForge技能锻造** — 重复工作流自动提炼为技能，收集反馈持续进化（非静态skill文件）
6. **Agent Template模板化** — 从Raven出发定义场景Agent，可分享/商业化，属于创建者
7. **Deep Research工具化** — 深度研究作为可插拔工具（`raven deep-research enable`），MiroThinker多源调查

### 多引擎架构图

```
Channels / TUI / Gateway
       ↓
  Raven Spine (submit → lanes → emit)
       ↓
  Agent Loop (tools · skills · providers)
       ├── Context Engine   (legacy / curator)
       ├── Memory Engine    (EverOS / local skills / SkillForge)
       ├── Proactive Engine (Sentinel / scheduler / nudge policy)
       ├── TokenWise        (usage / cache / routing)
       ├── Tracing          (LLM / tool / memory spans)
       ├── Eval Engine      (task judgement)
       └── Evolver          (benchmark-driven self-evolution)
```

### 与Claw系统对比

| Raven能力 | Claw现有模块 | 差距分析 |
|-----------|-------------|---------|
| Spine脊柱架构 | agent_orchestrator | Claw缺乏单入单出+per-session lane模式 |
| Sentinel主动引擎 | 无 | **全新能力** — Claw完全被动响应 |
| Evolver自进化管道 | claw_integration | Claw进化靠外部GitHub扫描，缺乏线束内自评估 |
| TokenWise | model_scheduler | Claw有模型路由但无缓存放置/用量优化 |
| SkillForge | skill_system | Claw的skill静态写入，缺乏反馈驱动进化 |
| Agent Template | agent_core | Claw无模板化Agent定义/分享机制 |

### 改进建议

1. **[P0] agent_orchestrator: Spine脊柱架构** — 引入submit/emit单入单出模式+per-conversation lane，解决多会话消息乱序问题。Feature引擎通过显式handoff接入而非直接import

2. **[P0] agent_orchestrator: Sentinel主动引擎** — 新增Sentinel模块，含nudge策略（检测到可行动场景主动触发）+调度器（定时巡检）。Claw从被动响应升级为主动Agent

3. **[P0] claw_integration: Evolver基准驱动自进化** — 线束内嵌评估管道，自动运行基准测试→评估结果→调整线束参数。补充现有外部GitHub扫描进化机制

4. **[P1] model_scheduler: TokenWise令牌智能** — 在模型路由基础上增加：用量追踪（per-session token budget）+缓存放置（自动缓存重复prompt响应）+路由策略（根据token预算选模型）

5. **[P1] skill_system: SkillForge反馈驱动进化** — 技能从"一次创建静态文件"升级为"工作流→自动提炼→反馈收集→持续迭代"的闭环

6. **[P1] agent_core: Agent Template模板化** — 定义Agent Template标准（含场景/personality/工作流策略/技能集/集成配置），支持模板分享与商业化
